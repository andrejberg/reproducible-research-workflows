# Example module

Shows the layout every module follows, and lets you try the setup command. It teaches
nothing else.

## Starting state

The experiment `2026-11-03_first-look`: a README, its metadata, a small data file and a
starting notebook.

## How to run it

In a terminal (File → New → Terminal):

```bash
python ~/setup_module.py example
```

Then open `work/rrw-workshop/experiments/2026-11-03_first-look/` in the file browser and
work there. Work inside `work/` only: everything else is reset at the next start.
